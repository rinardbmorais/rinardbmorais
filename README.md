### 📦 Módulos do Sistema

| Módulo | Descrição |
|---|---|
| 📊 **Dashboard** | Visão geral em tempo real — reservas do dia, OS ativas, receita do mês e fila de atendimento |
| 📦 **Catálogo** | Gestão de itens com disponibilidade em tempo real. Inativos ocultados em reservas e no bot |
| 📅 **Reservas** | Criação com rota e frete automático por cidade, cancelamento com motivo obrigatório |
| 🚚 **Ordens de Serviço** | Controle logístico de entrega e recolhimento com impressão |
| 👥 **Clientes** | Cadastro completo com histórico de reservas e total gasto |
| 💰 **Financeiro** | Lançamentos automáticos por reserva, filtro por mês, controle de pagamentos |
| 🤖 **Bot WhatsApp** | Atendimento automatizado — orçamento, reserva, consulta e fila de atendimento humano |
| ⚙️ **Configurações** | Dados da empresa, rotas com frete por cidade, perfis de acesso |

### 🤖 Bot WhatsApp — Fluxos

```yaml
menu:
  - "1️⃣  Atendente   →  notifica atendente, bot silencia até digitar *menu*"
  - "2️⃣  Orçamento   →  tipo evento > data > endereço > itens > total"
  - "3️⃣  Reserva     →  fluxo completo com responsável e devolução"
  - "4️⃣  Consulta    →  busca reservas ativas pelo telefone"

dashboard_alertas:
  - Badge piscante + alarme sonoro para nova solicitação de atendimento
  - Polling a cada 15 segundos
```

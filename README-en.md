### 📦 System Modules

| Module | Description |
|---|---|
| 📊 **Dashboard** | Real-time overview — daily reservations, active service orders, monthly revenue, and support queue |
| 📦 **Catalog** | Item management with real-time availability. Inactive items hidden from reservations and the bot |
| 📅 **Reservations** | Creation with automatic route and freight per city, cancellations with required reason |
| 🚚 **Service Orders** | Delivery and pickup logistics control with printable records |
| 👥 **Clients** | Full registration with reservation history and total spending |
| 💰 **Financial** | Automatic entries per reservation, month filter, payment tracking |
| 🤖 **WhatsApp Bot** | Automated support — quotes, bookings, lookups, and human support queue |
| ⚙️ **Settings** | Company data, delivery routes with freight per city, access profiles |

### 🤖 WhatsApp Bot — Automated Flows

```yaml
menu:

  - "4️⃣  Lookup     →  finds active reservations by phone number"
```
